
# Togetherly

### Small Actions. Stronger Communities.

Togetherly is a community-driven social development events platform where people can discover, create, and participate in local volunteering activities.

## Live Website

Not deployed yet. The Vercel URL will be added after deployment.

## Features

- Discover upcoming community service events.
- Create and manage volunteering events.
- Join events and connect with other volunteers.
- Secure authentication with Better Auth.
- Track joined events and personal participation.
- Responsive design for mobile, tablet, and desktop.
- Light and dark theme support.
- Profile management and volunteer statistics.

## Technology Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- Express.js
- MongoDB
- Better Auth
- JWT

## Run Locally

1. Clone the repository.
2. Navigate to the client directory.
3. Install dependencies using `npm install`.
4. Configure environment variables.
5. Start the development server using `npm run dev`.

## Project Purpose

Togetherly aims to encourage community participation and make local social development activities easier to discover and organize.
